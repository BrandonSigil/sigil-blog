# Sigil Studio

Independent music editorial, release calendar, and web design sandbox live at [sigil.studio](https://sigil.studio).

## Stack

- **Framework:** Astro 5 + MDX + RSS + Sitemap
- **Share Cards:** Dynamic Open Graph / recap cards rendered via `satori` + `sharp`
- **Typography & Styling:** `@fontsource/space-grotesk` + custom CSS
- **Hosting & Telemetry:** Vercel + Vercel Speed Insights

## Development

```bash
yarn install
yarn dev
yarn build
```
